# Home Workspace Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the home screen into a workspace: generated entity summaries wired into both agents' context, a dynamic Jev target decision, an always-shown confirmation card before any run, agent-side clarification with live dropdowns, a searchable library with a docked composer, and a typed view-transition that assembles the editor.

**Architecture:** Summaries are generated by the worker (vision for frames, cheap chat for asset/project) and stored on the entity rows; both the home decision and every run prompt read them. `POST /api/runs` splits into a proposal phase (guardrail + Jev decision, no run) and a confirm phase (starts the run from the stored proposal). The agent gains `ask_user`, and the app enriches known question ids with live dropdowns on the existing Anvia interaction contract. Navigation uses TanStack Router's typed view transitions with named elements.

**Tech Stack:** TypeScript, Drizzle + PostgreSQL, Express, React 19 + TanStack Router/Query, `@anvia/core` (Agent, `createQuestionTool`, `generateCompletion`), `@anvia/durable`, Vitest, supertest.

**Spec:** `docs/superpowers/specs/2026-10-12-home-workspace-design.md`

## Global Constraints

- Node >= 22.16, pnpm 10; Conventional Commits (commitlint + husky run on every commit); branch `feat/multi-model-choice`, never merged.
- TDD for every pure unit: failing test first, then the minimal implementation, then the suite; the static gate (`pnpm typecheck && pnpm lint && pnpm test`, no cache) runs before each commit.
- **Never read `.env` contents.** Inject it with `pnpm exec dotenv -e .env -- <cmd>`; inspect only non-secret lines you wrote yourself (`grep '^TAVILY_API_KEY=' .env` is fine, printing the value is not).
- Fail loud, name the cause (`MODEL_CANNOT_READ_IMAGES`, `RUN_IN_PROGRESS`, `PROJECT_LIMIT_FOR_DECISION`, `PROPOSAL_EXPIRED`, `NOT_FOUND`, …). No silent substitutions, no deterministic fallbacks.
- Live agent/UI testing uses `muse-spark-1.3-contributor` only; subagents run on `opencode-go/deepseek-v4.1-flash#max` only.
- UI uses DESIGN.md tokens and existing primitives (`Card`, `Field`, `TextInput`, `SelectControl`, `IconButton`, `Tooltip`, `Composer`, `RunConsole`, `SpriteThumb`); copy is English; no new colors, no soft shadows, no rounded corners.
- Durable invariants: one run per thread, bindings before `runtime.resume()`, approvals/questions survive restarts.
- The turborepo-managed block in `AGENTS.md` is never touched.
- Summaries never block anything: a missing or failed summary is an absent line, never a guessed value.

## Review Focus

1. **Zero projects, zero assets.** A home prompt with an empty library must propose `project: "new"` and confirm into a created project + asset; empty option sets must not crash the decision or the card (Tasks 5, 7, 8).
2. **Stale proposals.** A proposal left open while the user types another prompt (or opens a second tab) must fail with `PROPOSAL_EXPIRED`/`NOT_FOUND` and never start a stale run; a consumed proposal must not start twice (Task 7).
3. **Summarizer outages.** A failed frame/asset/project summary must leave the old value and must never delay or block a run; decisions and prompts simply omit the line (Tasks 2, 3, 4).
4. **Clarification answers.** `ask_user` answers that carry a foreign or missing asset id, `new`, `none`, or free text must land as named tool failures the agent can recover from, never as a silent bad bind (Tasks 9, 10, 12).
5. **Transition fallbacks.** A browser without the View Transitions API, or `prefers-reduced-motion`, must navigate plainly with no stuck page and no console error (Task 14).

export type FrameSummaryInput = {
  assetName: string;
  frameName: string;
  width: number;
  height: number;
  paletteSize: number;
  paintedPixels: number;
};
export type AssetSummaryInput = {
  name: string;
  width: number;
  height: number;
  paletteSize: number;
  projectDescription: string;
  frames: Array<{ name: string; summary: string }>;

export type ProjectSummaryInput = {
  name: string;
  description: string;
  styleNotes: string;
  assets: Array<{ name: string; summary: string }>;
};
export type SummarizerDeps = {
  /** Loads and rasterizes one frame; undefined when the frame is gone. */
  loadFrame(id: string): Promise<{ input: FrameSummaryInput; png: Buffer } | undefined>;
  loadAsset(id: string): Promise<AssetSummaryInput | undefined>;
  loadProject(id: string): Promise<ProjectSummaryInput | undefined>;
  summarizeFrame(input: FrameSummaryInput & { png: Buffer }): Promise<string>;
  summarizeText(prompt: string): Promise<string>;
  save(kind: SummaryKind, id: string, summary: string): Promise<void>;
  /** Test seam; production debounces with setTimeout. */
  schedule?: (run: () => void, delayMs: number) => void;
};
export type Summarizer = {
  queue(kind: SummaryKind, id: string): void;
  flush(): Promise<void>;
};

````ts
export const SUMMARY_LIMIT = { frame: 160, asset: 240, project: 240 } as const;

/** Collapse whitespace, strip markdown, cut at a word boundary. */
export function clampSummary(text: string, limit: number): string {
  const flat = text
    .replace(/```[\s\S]*?```/g, " ")
    .replace(/[*_#>`]/g, "")
    .replace(/\s+/g, " ")
    .trim();
  if (flat.length <= limit) return flat;
  const cut = flat.slice(0, limit + 1);
  const at = cut.lastIndexOf(" ");
  return (at > 0 ? cut.slice(0, at) : cut.slice(0, limit)).trim();
}

export function buildFrameSummaryPrompt(input: FrameSummaryInput): string {
  return [
    "Describe this pixel-art frame in one sentence (under 160 characters).",
    `Asset: ${input.assetName}. Frame: ${input.frameName}. Canvas: ${input.width}×${input.height}. Palette: ${input.paletteSize} colors. Painted pixels: ${input.paintedPixels}.`,
    "Name the subject and its main colors. No markdown, no quotes, no invented detail.",
  ].join("\n");
}

export function buildAssetSummaryPrompt(input: AssetSummaryInput): string {
  const frames = input.frames
    .map((frame) => `- ${frame.name}: ${frame.summary || "(no summary yet)"}`)
    .join("\n");
  return [
    "Summarize this pixel-art asset in one or two sentences (under 240 characters).",
    `Name: ${input.name}. Canvas: ${input.width}×${input.height}. Palette: ${input.paletteSize} colors. Project: ${input.projectDescription || "(none)"}.`,
    `Frames:\n${frames}`,
    "Use only what the frames show; do not invent content. No markdown.",
  ].join("\n");
}

export function buildProjectSummaryPrompt(input: ProjectSummaryInput): string {
  const assets = input.assets
    .map((asset) => `- ${asset.name}: ${asset.summary || "(no summary yet)"}`)
    .join("\n");
  return [
    "Summarize this pixel-art project in one or two sentences (under 240 characters).",
    `Name: ${input.name}. Description: ${input.description || "(none)"}. Style notes: ${input.styleNotes || "(none)"}.`,
    `Assets:\n${assets}`,
    "Use only what the assets show; do not invent content. No markdown.",
  ].join("\n");
}

export function createSummarizer(deps: SummarizerDeps): Summarizer {
  const pending = new Map<string, { kind: SummaryKind; id: string }>();
  const schedule = deps.schedule ?? ((run, delay) => void setTimeout(run, delay));
  return {
    queue(kind, id) {
      const key = `${kind}:${id}`;
      if (pending.has(key)) return;
      pending.set(key, { kind, id });
      schedule(() => void flushOne(key), 5_000);
    },
    async flush() {
      for (const key of [...pending.keys()]) await flushOne(key);
    },
  };
  async function flushOne(key: string): Promise<void> {
    const entry = pending.get(key);
    if (!entry) return;
    pending.delete(key);
    try {
      let summary: string | undefined;
      if (entry.kind === "frame") {
        const loaded = await deps.loadFrame(entry.id);
        if (!loaded) return;
        summary = await deps.summarizeFrame({ ...loaded.input, png: loaded.png });
      } else if (entry.kind === "asset") {
        const input = await deps.loadAsset(entry.id);
        if (!input) return;
        summary = await deps.summarizeText(buildAssetSummaryPrompt(input));
      } else {
        const input = await deps.loadProject(entry.id);
        if (!input) return;
        summary = await deps.summarizeText(buildProjectSummaryPrompt(input));
      }
      const clamped = clampSummary(summary ?? "", SUMMARY_LIMIT[entry.kind]);
      if (clamped.length > 0) await deps.save(entry.kind, entry.id, clamped);
    } catch (reason) {
      console.error(
        `[summary] ${entry.kind} ${entry.id}: ${reason instanceof Error ? reason.message : reason}`,
      );
    }
  }
}
````

(The frame branch clamps the provider's reply inside `summarizeFrame`'s caller path; the asset/project branches clamp here. Both use the same `SUMMARY_LIMIT`.)

```ts
app.post("/internal/summaries/refresh", async (req, res) => {
  if (!authorized(req)) return res.status(401).end();
  const body = z
    .object({ kind: z.enum(["frame", "asset", "project"]), id: z.string().min(1) })
    .safeParse(req.body);
  if (!body.success)
    return res.status(422).json({ message: "kind and id are required." });
  if (!summarizer)
    return res.status(503).json({ message: "Add AGENT_API_KEY to summarize." });
  summarizer.queue(body.data.kind, body.data.id);
  await summarizer.flush();
  res.status(204).end();
});
```
